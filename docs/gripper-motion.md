# 夹爪硬件计步与运动规划

适用通道：`MOTOR_GripperMove`，物理 4 号接口，PA3 / TIM5_CH4。
仅修改夹爪；皮带和进退轴的计步算法仍沿用原实现。

## 硬件路径

不需要额外接线。初始化在 `main.c` 的 USER CODE 2 区调用
`SMD_GripperCounterInit()`，在 TIM10 调度启动前完成。

1. TIM5_CH4 保留 PWM1、高有效、约 50% 占空比，驱动原 PA3。
2. TIM5 未使用的 CH1 配成内部 PWM2，CCR1 与 CCR4 同时更新；写预装载
   时短暂设置 UDIS，防止两个通道被锁存到不同周期。不使能
   CH1 引脚输出。CH4 脉冲下降沿对应 OC1REF 上升沿。
3. TIM5_TRGO=OC1REF；TIM3 经 ITR2、外部时钟模式 1 数完整脉冲。
4. TIM3_TRGO=ENABLE；TIM5 经 ITR1、门控模式运行。
5. 定步移动 N 步时，TIM3 配为单脉冲模式，ARR=N、CNT=1。
   完成 N 个脉冲后 TIM3 溢出并自动清 CEN，关闭 TIM5 门控。
   此时 PA3 已为低电平；即使 CPU 延迟响应，也不会再生成下一步。
   从 CNT=1 起数是为了规避 ARR=0 时不能计数的单步边界。
6. TIM3 中断及 1ms 调度结算位置和累计脉冲数，随后清理软件运动状态。

停止到目标位置依赖硬件门控，而非 TIM3 中断延迟。连续调速、限位寻零
时 TIM3 自由计数，周期读取并处理 16 位回绕。正常工作不需要每步中断。

位置记录的是完整脉冲。急停若中断正在输出的高电平，会读取实际 PA3
电平补记该步；读取 GPIO 避免把尚未生效的 CCR 预装载值误认为当前占空比。
启停和换向的计数结算使用保存/恢复 PRIMASK 的临界区。

## 普通 STEP 目标的执行流程

普通目标仍是 16 位绝对位置，`剩余步数=目标位置-当前硬件计步位置`。

1. 确认方向及限位、急停和气缸联锁。方向改变后至少等待一个 1ms 周期再发步。
2. 将剩余步数装入 TIM3 的硬件预算，从 50Hz 起步。
3. 每 1ms 按 PU 上限、ACC 和 JRK 更新速度与带符号加速度。
   长行程会达到 PU 匀速；短行程会提前减速，不强求达到最高速度。
4. 使用当前速度、带符号加速度、ACC、JRK，计算减速到 100Hz 的
   三角形/梯形加速度曲线所需步数。PU 小于 100Hz 时，以 PU 为收尾速度。
5. 剩余步数不大于刹车距离加动态余量时，锁定减速阶段。
   余量为 `当前速度×3ms+2步`，代替原固定 100 步缓冲。
   主要用于离散调度、PWM 预装载及频率取整的补偿。
6. 最后仍允许短暂低速收尾；硬件预算耗尽后自动截止完整脉冲。
   软件在下一个调度周期清除运行标志、恢复 PU=1。

PU 始终保留用户指定的巡航上限，不再在减速时改写成 100。
若 PU=1，则减速并暂停，保留目标；后续提高 PU 可继续向该目标移动。
SP=0/全部急停仍立即停止并取消运动。SP>1 仍是连续定频模式。

中途改写普通目标时，先在原方向减速到 50Hz、停下并结算，下一周期
从实际停止位置重新规划。旧定步预算在减速期间仍有效，防止越过原目标。
此实现没有把运行中目标更新处理为连续轨迹拼接。

STEP=0 和 STEP=0xffff 继续表示原点/远端限位寻零，不按普通定步目标处理。
这两种模式保留原有调速逻辑，但位置计步同样来自 TIM3。

## 验证与实机检查

主机测试：

```sh
gcc -std=c99 -O2 -Wall -Wextra -Werror tests/test_gripper_profile.c -lm -o /tmp/test_gripper_profile
/tmp/test_gripper_profile
python3 tests/test_gripper_counter.py
```

运动仿真覆盖 1～65534 步、100/1600/4000/8000Hz，并模拟 ARR/CCR
在溢出时锁存。刹车距离还与独立细步长数值积分比较。
计数测试使用生产函数及寄存器模型，覆盖单步、双向、回绕、延迟中断截止、
急停高电平补步和重复停止。测试模型不能证明芯片内部同步及电气边沿正确。

上板需用逻辑分析仪同时确认 PA3 与驱动器 STEP 端：1/2/10/1000 步、
两个方向、重复运动、运动中修改目标、PU 暂停/恢复、急停、两端限位。
对照实际脉冲数量与位置回读，确认末步完整且不多发下一步。
初次用低速、短行程检查，再提升到原有 PU/ACC/JRK 参数。
硬件脉冲计数不检测电机机械失步，实际负载下的速度与加减速仍需验证。

本环境未进行 Keil 完整固件链接、下载或实机测试。
